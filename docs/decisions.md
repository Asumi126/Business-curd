## 1. 技術構成の選定

### Next.js 16 + React 19 + Tailwind CSS v4 を採用
- **理由**: ユーザーとの最初の合意通り。本格的なWebアプリにふさわしく、後から拡張しやすい
- **代替案を捨てた理由**:
  - 純HTML/CSS/JS は将来のクラウド連携が困難
  - Vite は学習機会としてもNext.jsより馴染みが薄い
- **トレードオフ**: 初回 `npm install` に数分かかるが、`start.command` で隠蔽

### サーバーレス（ローカル動作のみ）
- **理由**: ユーザー要望「自分専用」「アカウント不要」「すぐ使える」に最適
- **メリット**:
  - 個人情報が外部に出ない（プライバシー◎）
  - サーバー費用ゼロ
  - インターネット接続不要で動く
- **デメリット**: 複数端末で同期できない（将来の課題）

### PDF生成: jsPDF + html-to-image
- **理由**: ブラウザ内で完結、サーバー不要
- **代替案**: react-pdf を捨てた → CSSでデザインしたテンプレを再現するのが難しい
- **品質**: pixelRatio 4 で約670dpi 相当。一般的な印刷品質（300dpi）以上

### QRコード: qrcode ライブラリ
- **形式**: vCard 3.0（業界標準）
- **理由**: iPhone/Android のカメラで読み取ると連絡先に自動登録される

## 2. UX設計

### ウィザード形式（8ステップ）を採用
- **理由**: ユーザー要望「初心者でもデザイナーじゃなくても、質問に答えるだけで作れる」
- **ステップ構成**:
  1. ようこそ（説明）
  2. お名前
  3. お仕事
  4. 連絡先
  5. ウェブ・SNS
  6. ロゴ
  7. デザイン選択
  8. 完成・ダウンロード
- **各ステップで提供する補助**:
  - 例文（プレースホルダ＋「例: 」表示）
  - ヒント（💡で「なぜ必要か」を説明）
  - 任意項目は明示（スキップしやすく）

### ライブプレビュー
- **配置**: PCでは右サイドバーに常時表示、スマホでは右下にトグルボタン
- **理由**: 入力中も「どんな名刺になるか」が見えるので、初心者でも迷わない

### 自動保存（localStorage）
- **理由**: ユーザーが途中で休んでも続きから再開できる
- **キー**: `mycardmaker:v1:userdata`, `mycardmaker:v1:template`
- **トリガー**: 入力のたびに即保存

## 3. テンプレート設計（24種類）

### スコープ判断
- ユーザー要望は「最低15種類、スタイリッシュからポップまで」
- → **24種類**を実装（30%増）

### カテゴリ分類
| カテゴリ | 件数 | 例 |
|---|---|---|
| ミニマル | 3 | 白地・黒地・ストライプ |
| ビジネス | 3 | コーポレートブルー・ネイビー・斜め分割 |
| モダン | 5 | グラデ青・サンセット・ネオン・テック・ゴールド |
| ポップ | 3 | イエロー・ミント・ボールドレッド |
| クリエイティブ | 4 | カラフル・ジオメトリック・マガジン・手書き |
| 和風 | 2 | 侘・朱 |
| ナチュラル | 4 | グリーン・ローズ・パステル・ヴィンテージ |

### ロゴ配置の自動化
- **`hasOwnLogo: true`**: テンプレートが内部でロゴを配置（コーポレートブルー・和モダン朱・ポップイエロー）
- **`hasOwnLogo: false`**: `CardRenderer` が右上に小さなロゴオーバーレイを自動追加
- これにより、ユーザーがロゴをアップロードすると、どのテンプレでも適切に表示される

### `logoTone: 'light' | 'dark'` メタデータ
- 暗めのテンプレ（黒地など）にはロゴオーバーレイ背景を半透明白に
- 明るめのテンプレには白背景を強めに

## 4. 印刷規格の決定

### サイズ: 91 × 55mm（日本標準）
- 塗り足し3mm込みで 97 × 61mm

### 出力形式の優先順位
1. **PDF**（印刷発注向け）
2. **PNG**（SNS・デジタル用）
3. **QRコード**（裏面に自動埋め込み）

### 両面対応
- **デフォルト裏面**: 大きなQRコード + 連絡先サマリ
- ユーザーが「両面PDF」をチェックボックスでON/OFF可能

### カラーモード: RGB
- **判断**: ほぼすべての印刷会社が RGB PDF を受領可能
- **代替案を捨てた理由**: CMYK 変換は色がくすむ＆ライブラリが重い
- **ユーザーへの説明**: マニュアルに記載

## 6. セキュリティ・プライバシー

### 設計方針: ローカル限定
- インターネットへの通信は **一切しない**
- 全データはブラウザの localStorage に保存
- ロゴ画像も base64 でブラウザ内に保持

### マニュアル記載
- 「データはどこにある？」テーブル
- 「あなたができる対策」セクション（ロックパスワード等）
- Q&A（クラウド保存・他人にPC貸す時など）

### 確認可能性
- 全ソースコードは `web/app/` 以下に存在
- ネットワーク通信が無いことは `grep -r "fetch\|axios\|XMLHttp" app/` で確認可能

## 7. 起動の簡略化

### `start.command`（ダブルクリック起動）
- 初回: `npm install` を自動実行
- 2回目以降: 即起動
- ブラウザを自動で `http://localhost:3000` に開く
- Node.js 未インストールの場合はわかりやすいエラーメッセージ表示

### macOS の Gatekeeper 対応
- 初回ダブルクリックで「実行できません」と出ても、
  「右クリック → 開く」で1回だけ承認すれば以降は普通にダブルクリックで動く
- マニュアルにこの手順を明記

## 8. 独断で行った変更（ユーザー要望の解釈）

| 項目 | 当初要望 | 実装 | 理由 |
|---|---|---|---|
| テンプレ数 | 15種以上 | **24種** | 余裕を持たせて選択肢を増やした |
| デザイン傾向 | 「お任せ」 | 全ジャンル網羅 | 朝に好みが明確になっても対応できるように |
| ステップ数 | 仕様不明 | 8ステップ | 「答えるだけ」体験を最大化 |
| ロゴ配置 | 「自動配置」 | テンプレ別に最適位置を実装 | デザイン品質を最優先 |
| 印刷規格 | 「主要会社で受領可能」 | RGB + 塗り足し3mm | 国内主要4社で確認可能な汎用仕様 |
| デプロイ | 「ローカル」 | `start.command`実装 | パソコン操作が苦手な人でも開けるように |
