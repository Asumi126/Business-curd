# My Card Maker — 要件定義書 v1.1

**作成日**: 2026-05-09
**ステータス**: 確定（夜間自律実装フェーズ）

---

## 1. プロジェクト概要

**プロジェクト名**: My Card Maker（仮）
**一行説明**: 自分用の名刺を、テンプレートから選ぶだけで作れて、印刷発注用PDF・画像・デジタル名刺（QR）として書き出せる個人ツール。

## 2. 背景・目的

- 名刺を作り直したいときに、いつでも自分で作れるようにしたい
- 印刷発注までかけられる品質のPDFを出力したい
- まずは個人ユースに割り切って、サービス化は将来検討
- 一晩で作りきって、すぐ実用に移せるレベルを目指す

## 3. ターゲットユーザー

- **メイン**: 自分（個人事業主・フリーランス）
- 将来的に個人事業主・フリーランス全般に拡張可能性あり

## 4. ゴール（何ができたら成功か）

- [ ] テンプレートを選んで自分の情報を入れたら名刺が完成する
- [ ] 印刷発注に出せるPDFが出力できる（91×55mm + 塗り足し3mm）
- [ ] PNG画像でも保存できる
- [ ] QRコード付きデジタル名刺としても使える
- [ ] スマホ・PC両方で使える
- [ ] アカウント登録なしですぐ使える

## 5. 機能一覧（MVP）

### 必須機能
1. **テンプレート選択**：15種類以上から選ぶ
   - スタイリッシュ系・ポップ系・ビジネス系・和風・ナチュラル系・クリエイティブ系などバラエティ豊富に
2. **情報入力フォーム**
   - 氏名（漢字・ローマ字）
   - 肩書き
   - 屋号・会社名
   - 電話番号
   - メールアドレス
   - 住所
   - ウェブサイトURL
   - SNS（任意）
   - プロフィール画像/ロゴ（任意）
3. **リアルタイムプレビュー**：入力中、テンプレに即反映
4. **PDF出力**：印刷発注向け（91×55mm + 塗り足し3mm）
5. **PNG出力**：SNSアイコン等で使える画像
6. **QRコード生成**：vCard形式（連絡先として読み取り可）
7. **localStorage保存**：ブラウザを閉じても入力内容が残る
8. **レスポンシブ対応**：スマホ・PC両対応

### 対象外（やらないこと）
- アカウント登録／クラウド保存
- 他人と共有する機能
- 課金・有料プラン
- 自由レイアウト編集（ドラッグ&ドロップ等）
- 多言語対応（日本語UIのみ）

| website | string | △ | https://example.com |
| sns.x | string | △ | @yamada |
| sns.instagram | string | △ | @yamada |

### システムデータ
- テンプレート定義（コンポーネント形式、15種類以上）
- localStorage キー: `mycardmaker:v1:userdata`

## 7. 技術構成

| 項目 | 選定 |
|------|------|
| フレームワーク | Next.js 15+ (App Router) |
| 言語 | TypeScript |
| スタイル | Tailwind CSS v4 |
| PDF生成 | jsPDF + html2canvas |
| QR生成 | qrcode |
| アイコン | lucide-react |
| 状態管理 | React useState + useContext |
| データ保存 | localStorage |
| デプロイ | ローカル実行（npm run dev または start.command） |

## 8. 制約条件

- 開発時間: **一晩**（5〜6時間想定）
- 予算: **0円**（オープンソースのみ使用）
- 開発者: AI（Claude）が自律実装
- 利用者: 開発者本人のみ（朝以降）

## 9. 印刷規格

- **サイズ**: 91 mm × 55 mm（日本標準名刺サイズ）
- **塗り足し**: 上下左右 3mm（仕上がりサイズ97×61mm）
- **解像度**: 300dpi 相当
- **カラーモード**: RGB（多くの印刷会社が受領可能）
- **出力形式**: PDF（推奨）/ PNG（補助）

## 10. 受け入れ基準

- [ ] 起動：`start.command` ダブルクリックで起動できる
- [ ] テンプレ：15種類以上から選択できる
- [ ] 入力：必須項目を入力できる
- [ ] プレビュー：入力内容がリアルタイムで反映される
- [ ] PDF：印刷発注に使えるサイズで出力できる
- [ ] PNG：画像として保存できる
- [ ] QR：vCard形式のQRが生成される
- [ ] 保存：ブラウザを閉じても入力内容が残る
- [ ] レスポンシブ：スマホでも操作できる
